# PRISM

월가아재의 Valley AI(valley.town)에서 아이디어를 얻은 개인 투자 리서치 앱.
핵심 흐름: **티커 입력 → 주가·재무 추이 확인 → Peer Group/PER·PBR 비교 → 간단 DCF 밸류에이션(2-stage 성장·역산 성장률·민감도 분석) → AI 해설**.

## 설치

```bash
pip install -r requirements.txt
```

## 설정

`.env.example`을 `.env`로 복사하고 OpenAI API 키를 채워넣는다.

```bash
cp .env.example .env
```

```
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=
OPENAI_MODEL=gpt-4o-mini
ECOS_API_KEY=...
```

API 키가 없어도 재무 데이터 조회와 DCF 계산은 정상 동작하며, "AI 해설 생성하기" 버튼을 눌렀을 때만 OpenAI 키가 필요하다.

- `OPENAI_BASE_URL`은 선택 항목이다. 정식 OpenAI API를 쓰면 비워두면 되고, 학교/회사에서 발급하는 OpenAI 호환 LLM 게이트웨이(예: 경희대 ChatKHU)를 쓴다면 게이트웨이의 base URL을 넣는다. `OPENAI_API_KEY`에는 그 게이트웨이가 발급한 키를 넣으면 된다.
- `OPENAI_MODEL`은 기본값 `gpt-4o-mini`. 게이트웨이가 다른 모델명(예: `claude-sonnet-4-6`)을 요구하면 여기서 바꾼다.
- `ECOS_API_KEY`는 [한국은행 ECOS](https://ecos.bok.or.kr/api/)에서 무료로 발급받는다 (본인인증 필요). 없어도 매크로 지표 페이지는 동작하지만, 한국 CPI/M2가 FRED 미러링 데이터(갱신이 멈춘 과거 시점까지)로만 표시된다.
- `DART_API_KEY`는 [OpenDART](https://opendart.fss.or.kr/)에서 무료로 발급받는다. 없어도 앱 전체가 죽지는 않지만, 없으면: (1) 한국 종목의 yfinance 재무 완전 실패 시 대체 표시가 안 되고 기존처럼 안내만 뜨고, (2) "📢 최근 공시 (DART)" 섹션이 한국 종목에서도 안내 메시지만 뜨고 비활성화되며, (3) 맨 아래 "DART 원본 재무제표 (실험)" 섹션이 비활성화된다.

## 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열리며, 사이드바에서 티커와 DCF 가정치를 입력하면 된다.

- 미국 주식: `AAPL`, `MSFT`, `NVDA` 같은 티커 그대로 입력 (달러로 표시)
- 한국 주식: 6자리 종목코드(`005930` 등)를 입력하면 코스피(.KS)/코스닥(.KQ)을 자동 판별 (원화로 표시)
- 한국 종목명(`삼성전자`, `삼성` 등 한글)을 입력하면 이름으로 검색해 6자리 코드를 찾아준다. 후보가 여러 개면 선택 목록이 뜬다 (Stock Research 페이지 전용, 부분일치 지원, 우선주도 검색됨)

- "Screener" 페이지에서는 기본 대형주 유니버스(미국/한국 약 15개씩, 자유롭게 추가/수정 가능)를 PER/PBR/배당수익률/배당성향/시가총액/통화 조건으로 필터링한다. 배당수익률·배당성향 하한은 한국(KRW)/미국(USD)에 서로 다른 값을 걸 수 있다. "스크리닝 실행" 버튼을 눌러야 데이터를 가져오고, 이후 필터 조작은 재조회 없이 즉시 반영된다.
- "Comparison" 페이지에서는 최대 4개 종목의 PER/PBR/시가총액을 나란히 비교하고, 매출성장률(YoY %)·순이익률(%) 추이를 겹쳐서 본다 (통화가 다른 종목의 절대금액을 직접 겹치면 왜곡되므로 비율 지표로 비교).
- "Macro Indicator" 페이지에서는 미국/한국의 물가(CPI/PCE/PPI)·금리·고용·성장·통화 지표(미국은 3개월 국채·10Y-3M 금리차와 하이일드 스프레드·VIX·기대인플레이션·실질금리·달러인덱스 같은 "위험지표" 카테고리 포함)를 최대한 긴 시계열로 볼 수 있고, 아래 "혼합 지표" 섹션에서 CPI 상승률(YoY %)·실질금리·M2/명목GDP·한미 정책금리차 같은 조합 지표도 볼 수 있다. 맨 아래 "지표 겹쳐보기"에서는 단위가 다른 지표 2~3개를 골라 겹치는 기간의 첫 관측치=100으로 지수화해 한 차트에 비교할 수 있다.
- DCF 섹션에서는 "성장률 감쇠 사용" 체크박스로 초기→말기 선형 감쇠(2-stage) 성장 모델을 켤 수 있고, "현재 주가에 내재된 성장률"(시장이 요구하는 성장률 역산)과 성장률×요구수익률 민감도 표(괴리율, 색상 강조)를 함께 보여준다. "COE 자동제안"을 켜면 요구수익률을 무위험이자율(10년 국채금리, 실시간 조회) + 리스크프리미엄(사용자 가정)으로 자동 계산해준다(미국/한국 종목만 지원).
- DCF 계산이 끝나면 페이지 하단 "요약 내보내기"에서 종목 개요·밸류에이션·DCF 결과를 마크다운으로 보여주고 `.md` 파일로 다운로드할 수 있다.
- 한국 종목의 yfinance 재무제표 조회가 완전히 실패하면(예: 493330), 페이지가 멈추지 않고 "재무 추이" 자리에 OpenDART 원본 재무제표를 대신 보여준다(`DART_API_KEY` 필요, 출처를 명확히 표시함). 이때 DCF는 계산하지 않는다(재무 완전 실패 종목은 FCF도 없을 가능성이 높음). yfinance가 정상 조회된 종목에서는 페이지 맨 아래 "🔬 DART 원본 재무제표 (실험)"에서 DART vs yfinance 대조표를 볼 수 있다.
- 한국 종목이면 "재무 추이" 아래에 "📢 최근 공시 (DART)" 섹션이 yfinance 재무 조회 성공/실패와 무관하게 항상 뜬다(대형주도 최근 공시가 궁금할 수 있으므로 폴백이 아니라 상시 섹션이다). 조회 기간(1개월/3개월/6개월/1년)과 보고서명 키워드로 필터링할 수 있고, 각 공시는 DART 원문 페이지로 바로 연결되는 링크가 붙는다. 미국 종목은 "SEC EDGAR 연동 추후 지원 예정" 안내만 뜬다.

## 구조

- `app.py` — 엔트리포인트, `st.navigation`으로 페이지 라우팅만 담당
- `views/stock_research.py` — Streamlit UI (Stock Research: 종목 분석)
- `views/screener.py` — Streamlit UI (Screener: 다중 종목 필터링)
- `views/comparison.py` — Streamlit UI (Comparison: 다중 종목 비교)
- `views/macro_indicator.py` — Streamlit UI (Macro Indicator: 매크로 지표)
- `views/_cache.py` — `valley/`의 조회 함수를 `st.cache_data`로 감싸는 캐싱 전용 래퍼 (`valley/`는 Streamlit 의존성 없이 유지)
- `valley/data.py` — yfinance로 재무·주가 데이터 조회, 한국 종목코드 → 코스피/코스닥 심볼 자동 판별(`resolve_ticker`). 주가 추이(`get_price_history`)는 PER/PBR 계산과 달리 배당/분할 조정 종가(auto_adjust 기본값)를 그대로 쓴다 — 보기 좋은 추이가 목적이라 조정 종가가 맞다
- `valley/peers.py` — Yahoo Finance 유사 종목(Peer Group) 목록, PER/PBR/배당수익률/배당성향/ROE 스냅샷·연도별 PER/PBR 밴드, 밸류에이션 표 포맷터(`build_valuation_table`). PER/PBR은 모든 종목을 최근 확정 회계연도(FY) 재무제표로 직접 계산해 통일한다 (Yahoo `trailingPE` 등 TTM 지표는 쓰지 않음 — 미국은 TTM, 한국은 FY로 기준이 섞이는 문제를 피하기 위함). Fwd PER은 Yahoo의 `forwardPE`(향후 12개월 컨센서스 기반)를 그대로 사용 — 미국뿐 아니라 애널리스트 커버리지가 있는 한국 대형주에도 값이 나온다. 배당수익률은 `info["dividendYield"]`가 이미 퍼센트 값(예: 0.32 = 0.32%)으로 오는 것을 실측 확인해 100으로 나눠 비율로 통일했고(그대로 쓰면 100배 부풀려짐), info에 없으면 배당 지급 이력(`t.dividends`) 최근 4회 합으로 폴백한다. 배당성향/ROE는 EPS·BVPS와 같은 회계연도(fin/bs 공통 최신 결산일)의 순이익·자본총계를 재사용해 계산한다
- `valley/valuation.py` — Simplified DCF 계산 (순수 함수, `valley/macro.py`의 `get_indicator_series`만 재사용). OCF(이자비용 차감 후) 기반 FCF를 COE로 할인해 Equity Value를 직접 산출한다. 순차입/상환 효과는 반영하지 않는다. `simplified_dcf`는 `growth_rate_terminal`을 지정하면 1년차→N년차 성장률이 선형 감쇠(2-stage)하고, 미지정 시 기존 단일 성장률과 수학적으로 동일하다(하위호환). `implied_growth_rate`는 현재 주가를 정당화하는 단일 성장률을 이분법으로 역산하고(해가 없으면 `ImpliedGrowthNotFoundError`), `sensitivity_grid`는 성장률×COE 격자별 내재가치/괴리율을 계산한다(둘 다 항상 단일 성장률 기준). `suggest_coe`는 무위험이자율(10년 국채금리, USD는 FRED `DGS10`/KRW는 `IRLTLT01KRM156N`)을 실측 조회해 사용자가 정한 리스크 프리미엄과 더한 COE를 제안한다 — ERP는 무료 데이터로 신뢰성 있게 추정할 방법이 없어 항상 사용자 가정치로 둔다
- `valley/report.py` — 종목 분석 결과(스냅샷·밸류에이션·DCF·COE 출처)를 마크다운 요약 문자열로 변환하는 순수 함수(`build_markdown_summary`). 계산된 값만 포맷팅하며 숫자를 새로 만들어내지 않는다
- `valley/formatting.py` — 통화별 금액(USD `$`, KRW `₩`), PER/PBR 배수, 배당수익률·배당성향·ROE 같은 비율(%) 표시
- `valley/ai_commentary.py` — OpenAI로 자연어 해설 생성
- `valley/macro.py` — FRED(공개 CSV, 키 불필요) + 한국은행 ECOS(한국 CPI·M2)로 매크로 지표 조회. `normalize_indexed()`는 시계열을 첫 관측치=100으로 지수화하는 순수 함수로, 단위가 다른 지표를 겹쳐볼 때 쓴다
- `valley/composite.py` — 원본 매크로 지표를 조합한 파생 지표(CPI 상승률, 실질금리, M2/명목GDP, 한미 정책금리차) 계산. 한국 명목GDP(FRED `NGDPSAXDCKRQ`)는 단위가 M2(ECOS, 십억원)와 달라(백만원으로 추정, 시리즈 자체엔 단위 표기가 없어 비율값을 역산해 확인함) 1000으로 나눠 맞춘다. 이 보정은 ECOS 기준으로 역산한 값이라 한국 M2/GDP는 `ECOS_API_KEY`가 없으면 계산을 아예 막는다 (FRED 폴백은 단위도 다르고 2017년 이후 갱신도 끊겨 있어, 고치는 것보다 막는 게 안전하다고 판단)
- `valley/krx.py` — 한국 종목명 → 6자리 코드 검색(`resolve_ticker`의 "앞단"). pykrx의 공개 함수 `get_market_ticker_list()`는 (설치 버전 1.2.8 기준) KRX 로그인 세션을 요구하도록 바뀌어 있어 `KRX_ID`/`KRX_PW` 없이는 "LOGOUT" 오류로 실패하는 것을 직접 재현 확인했다. 대신 로그인 없이 동작하는 `StockTicker`(pykrx 내부 모듈, `get_market_ticker_name`이 쓰는 것과 동일한 경로)에서 전체 상장종목 목록을 가져온다 — 공개 API가 아니라 향후 pykrx 버전이 바뀌면 깨질 수 있다
- `valley/dart.py` — OpenDART 원본 재무제표·공시 목록 조회. 세 가지 용도로 쓰인다: (1) **yfinance 재무 완전 실패 시 자동 폴백** — Stock Research의 "재무 추이" 자리를 대신 채운다(한국 종목만, yfinance가 부분적으로라도 값을 주면 폴백하지 않음), (2) 페이지 맨 아래 "🔬 DART 원본 재무제표 (실험)"에서 yfinance와의 대조표를 계속 볼 수 있다(yfinance가 정상 조회된 종목에서만 의미가 있어 그 경우에만 표시), (3) **"📢 최근 공시 (DART)"** — `get_dart_disclosure_list`가 공시검색 API(`list.json`)로 최근 공시 목록(접수일/보고서명/제출인/원문링크)을 최신순으로 가져온다. `bgn_de`는 항상 오늘 기준으로 역산해 명시적으로 넣고(비워두면 DART가 좁은 기본 범위만 줄 수 있음), 해당 기간에 공시가 없는 것(status="013")은 에러가 아니라 빈 리스트로 정상 반환해 조회 실패와 구분한다. corp_code(6자리 종목코드 → DART 고유번호) 매핑은 `st.cache_data`뿐 아니라 프로젝트 루트 `.dart_corp_code_cache.json`에도 저장해 앱 재시작 후에도 재사용한다(.gitignore 처리됨). 연결재무제표(CFS)를 우선 조회하고 없으면 별도(OFS)로 폴백하며, 어느 쪽을 썼는지 화면에 표시한다. 계정 매칭은 `account_id`(IFRS 표준/DART 확장 분류코드)를 우선으로 쓰고 한글 계정명은 폴백으로만 쓴다 — 실측 중 같은 한글 계정명("지배기업의 소유주지분")이 같은 응답 안에서 서로 다른 두 항목(순이익 귀속분 vs 포괄손익 귀속분)을 가리키는 걸 발견해서다. 당기순이익은 지배주주 귀속분(`ifrs-full_ProfitLossAttributableToOwnersOfParent`)을 우선 매칭한다 — yfinance의 Net Income과 실측 대조해보니 총계가 아니라 이 값과 일치했다(삼성전자·SK하이닉스·현대차 3사×3개년×3항목 전부 0.0000% 일치 확인)

## 주의사항

본 도구는 정보 제공 목적이며 투자자문이 아닙니다. 전부 무료/비공식 데이터 소스이며, PER/PBR/재무 추이는 trailing(과거 확정 실적) 기준입니다. Fwd PER만 Yahoo가 제공하는 컨센서스 기반 예외입니다. DCF는 순차입/상환을 반영하지 않는 근사치라 자본구조가 크게 바뀔 기업일수록 오차가 커질 수 있고, 결과는 입력한 가정치에 따라 크게 달라지므로 참고용으로만 활용하세요.

## 알려진 한계

- **저장소 없음**: DB/파일 캐시가 없어 화면을 그릴 때마다 실시간으로 외부 API를 호출한다 (`st.cache_data`는 프로세스 재시작 시 사라지는 인메모리 캐시).
- **Screener는 전체 시장 스크리닝이 아님**: `DEFAULT_UNIVERSE`에 하드코딩된 30개 종목(자유 편집 가능) 안에서만 필터링한다.
- **PER/PBR 밴드**: 연 4~5개 점의 스냅샷이며 일별 롤링 밴드가 아니다.
- 한국 종목의 `sharesOutstanding`이 우선주를 포함/제외 중 어느 쪽인지 미검증.
- **Fwd PER은 Yahoo 원본값 그대로**: 자체 계산·검증 로직이 없고, 애널리스트 커버리지가 없는 종목(주로 소형주)은 N/A로 표시된다. 한국 종목은 대형주 위주로만 값이 나오는 경향이 있다 (네이버/FnGuide의 컨센서스 PER과는 출처가 달라 소폭 차이가 날 수 있음).
- **배당수익률 폴백의 "4회 = 1년" 가정**: info에 배당 데이터가 없을 때 최근 배당 지급 4회 합으로 연간 배당을 근사하는데, 이는 분기배당 기업 기준이다. 반기·월배당 기업에서는 이 근사치가 실제 연간 배당과 어긋날 수 있다.
- **pandas가 2.3.3으로 고정됨**: pykrx 1.2.8이 `pandas<3.0`을 요구해 기존 3.0.3에서 다운그레이드했다. 이 프로젝트 코드 자체는 2.3.3에서 회귀 없이 동작 확인했지만, pandas 3.x로 다시 올리려면 pykrx 쪽 대안을 먼저 찾아야 한다.
- **한국 종목명 검색은 pykrx 비공개 모듈에 의존**: `valley/krx.py` 참고. KRX_ID/KRX_PW를 설정하면 공식 `get_market_ticker_list()` 경로도 쓸 수 있을 것으로 보이나 미검증.
- **달러인덱스(`US_DOLLAR`, FRED `DTWEXBGS`)는 흔히 아는 DXY(ICE 달러인덱스, 90~110대)가 아니다**: Fed의 무역가중 광의 달러지수로, 2006년 1월을 100으로 잡은 뒤 꾸준히 올라 최근엔 120대에서 움직인다 — "달러가 20% 고평가"라는 뜻이 아니라 이 지수 고유의 기준점 때문이다.
- **하이일드 스프레드(`US_HY_SPREAD`)가 낮을 때는 역사적 저점 근처일 수 있다**: 추가 시점(2026-07) 값이 약 2.7%로, 통상 언급되는 3~8% 범위보다 낮다. 데이터 오류는 아니고(값이 안정적이고 갱신도 최신) 신용시장이 이례적으로 잠잠한 시기로 해석해야 한다.
- **DART 폴백은 "yfinance 재무 완전 실패"에만 적용된다**: `get_financial_history`가 못 찾는 경우(예: 493330 지에프아이)만 대상이고, yfinance가 일부라도 값을 주는 경우(예: 큐캐피탈의 영업이익만 NaN)는 폴백하지 않는다 — 기존 값을 조용히 DART로 바꿔치기하면 대형주 검증 때 확인한 "당기순이익 총계 vs 지배주주 귀속분" 같은 정의 차이가 예고 없이 섞여들 위험이 있어서다. DCF도 이 폴백 대상이 아니다(재무 완전 실패 종목은 FCF도 없을 가능성이 높아 "계산 불가"로 처리).
- **공시 목록은 목록 + 원문 링크까지만 지원한다**: 공시 원문 "내용"은 파싱해서 가져오지 않는다(원문 페이지로 링크만 연결). 미국 등 해외 종목은 SEC EDGAR 연동이 없어 이번 버전에서는 지원하지 않는다. 한 번에 최근 30건까지만 가져온다(그 이상은 페이지네이션 미지원).
